# Code Counter

A fast, asynchronous Node.js utility to count non-empty lines of code across various programming languages in a directory.

## Supported Extensions

The script currently tracks the following extensions:
`c`, `cpp`, `bat`, `Makefile`, `sh`, `cc`, `h`, `hpp`, `pl`, `js`, `mjs`, `ts`, `py`, `java`, `rs`, `rb`, `go`, `cs`, `php`, `ps1`, `ruby`, `asm`, `as`, `s`, `nasm`, `jsx`, `tsx`, `hh`, `r`, `kt`, `ino`.
